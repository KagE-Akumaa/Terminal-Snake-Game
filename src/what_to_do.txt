Next Steps for Your Snake Game

Continuous Movement

Wrap your while loop in a game loop that runs until the snake hits a wall or itself.

User Input

Capture arrow keys (or WASD) to change SnakeDir dynamically.

Make sure input doesn’t block the loop — you can use non-blocking input or libraries like ncurses.

Food & Growth

Randomly place a food item on the grid ('*' for example).

If the head reaches the food, don’t remove the tail — snake grows.

Collision Detection

Check if new head collides with:

Wall → game over

Its own body → game over

Optional: Score

Count the number of food items eaten and display score.
